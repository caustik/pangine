# Contributing

Reproducible bug reports and focused design discussion are welcome.

Pangine 1.0 is complete and maintained, so code contributions are not being sought. Unless you explicitly state otherwise, any contribution intentionally submitted for inclusion in Pangine by you, as defined in the Apache-2.0 license, shall be dual licensed under the Apache License, Version 2.0 and the MIT license, without any additional terms or conditions.

Please do not submit sensitive information, model files, generated build output, or local state.
